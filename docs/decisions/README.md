# Decisions

Why nimbus is the way it is, for decisions that would be expensive to rediscover.

What belongs here: a decision whose reasoning cannot be recovered by reading the
code — a rejected alternative, a thing that was measured and killed, a rule that
future changes must respect.

What does not: anything the code already says. If reading `Sources/` would
regenerate it, it must not exist here. This is not a changelog and not a status
page; git already does those jobs.

A note here should read, years later, as "right, that is why" — not as "I could
have found this by opening the project."
